# Tidligere markedsplass (GapBook / håndverkere)

Denne mappa er den gamle Next.js-appen med Prisma, bookinger, innlogging, dashboard og success fee. Den bygges ikke og følger ikke med det statiske nettstedet.

Historikken ligger i git. Ikke importer håndverker-CSV eller kjør Prisma herfra som del av WeekSlot-bygget.

For å lese den gamle koden, se committene før grenen som gjorde WeekSlot om til leirkatalog.
