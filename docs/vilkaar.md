# WeekSlot — låste vilkår & P0 (2026-09-19)

## Posisjonering
WeekSlot selger ledig håndverkertid — timer, dager eller uker — til synlig pris, før tiden mister verdien. Ikke anbud.

## Fag (live fra start)
Maling/tapetsering, elektriker, rørlegger, tømrer/snekker, flis/mur, tak

## Geografi
NO+SE først: Oslo + Stockholm, deretter Bergen/Göteborg. DK(+FI) senere.

## Booking-enhet
- Min: 3 timer
- Maks: 1 uke
- Enheter: timer (≥3), dag, uke — synlig pris

## Penger
- Ingen kunde-depositum
- Jobbpenger: direkte bedrift ↔ kunde
- WeekSlot: 5 % success fee til bedrift i etterkant (månedlig faktura)
- Launch: 0 % på første 2 bookinger per bedrift, deretter 5 %
- Ikke mellommann på hovedbeløpet

## Avtale
Digital bookingavtale (checkbox + timestamp) ved book.
- Kunde: møter/er klar; sen avbestilling (<48 t) kan utløse bedriftens eget avbestillingsgebyr (maks synlig på slot; håndheves mellom partene)
- Bedrift: holder avsatt tid / «passer til»; egen avlys → ombooking/klage + synlighetstrekk ved gjentakelse

## P0 produkt
1. Bedriftsprofil (land, by, fag, org.nr)
2. Admin manuell godkjenning
3. Publisere slots
4. Kundesøk: sted + periode + fag
5. Booking + e-postbekreftelse + avtale
6. Success-fee-grunnlag (telling av bookinger for faktura senere)
